Изображения

Элемент img

Элемент img включает изображение в настоящий документ в место определения элемента. Элемент img не имеет значения — он замещается по ходу изображения, указанный в атрибуте src.

Альтернативный текст

Атрибут alt дает краткое описание изображения. Он содержит альтернативный текст, который отображается, если изображение не может быть выведено. Пользовательские агенты должны отображать альтернативный текст, если они не используют изображения или не сконфигурированы так, чтобы не показывать изображение (отключено показ изображений).

Размеры изображения

Атрибуты ширина и высота задают размеры области изображения. Если оба атрибута не заданы, размер изображения будет определен после его полной загрузки, после чего размеры области будут Изменения в размещении содержимого изображений. Если задан только один из атрибутов, второй размер будет вычислен в соответствии с пропорциями изображения и заданным атрибутом. При указании обоих атрибутов браузер «пишет» изображение в области с указанными размерами.

Атрибут размеры указывает размеры изображений для разных макетов страниц. Атрибут srcset задает путь к графическим файлам с указанием размера изображения и устройства.

Подпись к изображению

Для группировки любых элементов, изображений и подписей к ним используется элемент фигура. Он не должен быть непосредственно связан с основным содержимым документом и при его переносе в другое место. место смысл текста не должен меняться. Обычно применяется для иллюстраций, фрагментов кода, схем, графиков, диаграмм и т. д. Элемент figcaption содержит описание элемента figure. Он должен быть первым или ведущий член группы.

Элемент изображения

HTML-элемент picture служит контейнером для одного или более элементов. source и один элемент img для обеспечения проверки версии изображения для экрана различных размеров. Браузер рассмотрит каждый из дочерних элементов source и выбираем один, соответствующий лучшему совпадению; если совпадение между элементами source найдено не будет, то будет выбран файл, указанный атрибутом src элементом img. Затем выбранное изображение отображается в пространстве, занятом элементом img.

Оптимизация изображений

Для оптимизации скорости загрузки рекомендуется использовать современные форматы изображений WebP и AVIF (высокое сжатие, поддержка прозрачности) для фото и графиков, SVG для иконок и логотипов (вектор). Классические форматы JPEG (фото) и PNG (прозрачность) используются для совместимости с предыдущими версиями. браузерами. Форматы WebP и AVIF также можно использовать для анимированных изображений вместо GIF.
